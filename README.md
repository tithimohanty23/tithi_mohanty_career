# Tithi Mohanty Portfolio

A responsive, single-page biotechnology portfolio adapted from Tithi Mohanty's CV.

## Files

- `dist/index.html` — page content and structure
- `dist/styles.css` — responsive visual design
- `dist/script.js` — navigation, scroll state and reveal interactions
- `dist/Tithi_Mohanty_CV.pdf` — downloadable CV

## Run locally

Serve the `dist` directory with any static web server. For example:

```bash
python3 -m http.server 8000 --directory dist
```

Then open `http://localhost:8000`.
